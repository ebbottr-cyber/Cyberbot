# Gemini açıklama katmanı

Ollama bu modülün planından çıkarılmıştır. Gemini yalnızca Türkçe araştırma açıklamaları için planlanır; karar, risk ve emir yetkisi yoktur. Yerel sayısal modeller bağımsız kalır.

Varsayılan kapalı. Kullanıcı ücretsiz katmanı ve faturalandırmanın kapalı olduğunu doğrulamadan API etkinleştirilmez. Model kimliği yapılandırılabilir; güncel ücretsiz kota doğrulanmalıdır. API anahtarı ortam değişkeninde tutulur, GitHub'a veya loglara yazılmaz. Kota/hata durumunda yerel kural tabanlı açıklamaya dönülür. Kişisel portföy, kimlik bilgisi ve sırlar gönderilmez. Henüz API adaptörü uygulanmadı veya test edilmedi.
